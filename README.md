## Запуск
1. Установить Unity **6000.3.14f1** (через Unity Hub).
2. Открыть проект, открыть сцену `Assets/Source/Scenes/SampleScene.unity`.
3. Нажать **Play**.

## Что доделал бы, будь ещё ~2 часа
- **ReactiveValue без лишнего мусора для GC**: сейчас при каждом изменении значения я создаю временную копию списка подписчиков — чтобы подписчик мог безопасно отписаться прямо в своём колбэке. При частых изменениях это лишние аллокации. Переделал бы так, чтобы копии не было: помечать отписавшихся флажком и подчищать их после рассылки.
- **UI-manager**: анимации открытия/закрытия окон и динамическая подгрузка UI (Addressables/инстанс), а не статичные вьюхи на сцене с `SetActive`.
- **Защита от двойных переходов** в стейт-машине: если быстро нажать «Restart» дважды или новый переход начнётся поверх ещё не завершённого — лишний нужно отсекать. Сейчас от этого спасает только то, что кнопка отписывается в `Release()`.
- **Раскладка файлов и неймспейсы**: причесал бы структуру папок и довёл неймспейсы до единообразия.
